# Послідовність підготовки, 16.10.2026

1. Прочитано поточний англійський `main-SMPT.tex` і API графів, локального та макросимулятора. Обмежена незалежна перевірка вимог підтвердила: локальні індуковані графи, явні розміри спільнот, W як сума ваг; два напрямки одного неорієнтованого контакту. Перші два розділи пояснення записано до обробки мережі.
2. Перевірено первинну сторінку SocioPatterns і статтю Mastrandrea et al. Вибрано сенсорні контакти 2013 року, бо класи задають природні групи та доступні всі контактні кінці для контрольного графа. Не використано дружбу, синтетичні старі результати чи нові епідемічні запуски.
3. Завантажено два оригінали. Linux-клієнт не довіряв корпоративному TLS-сертифікату, повтор із підвищеним доступом не змінив результат; Windows curl із перевіркою ланцюжка та `--ssl-revoke-best-effort` отримав файли. Хеші й URL збережено.
4. Перша строга перевірка зупинилася на рядку 1473 через різні класи ID 28. Повна детермінована перевірка знайшла 1321 суперечливий кінець, усі для цього ID. Замість непомітної заміни введено правило пріоритету метаданих і варіант за контактними мітками. Невдалий початок збережено в журналі.
5. Встановлено 329 метаданих проти 327 контактних ID. Основна сукупність — спостережені кінці; два інші ID збережені в CSV і доступні як окрема альтернатива. До статті додано результати якості, пояснення секунд/інтервалів, знаменника та двох різних наближень (часова агрегація і SMPT).
6. Побудовано повний граф і 9 індукованих локальних графів. Збережено CSV, GraphML, W та W для альтернатив. Перевірено суми вузлів, ребер і ваг, симетрію й одиниці. Старі результати проєкту не змінювалися.
7. Обчислено характеристики структури та точний приклад нульової реальної і додатної агрегованої інтенсивності в одному фіксованому стані. Побудовано два рисунки зі збережених даних. До статті додано таблицю, рисунки, межі інтерпретації, відповідність API та питання для подальшої перевірки.
8. П'ять структурних тестів пройшли. Перевірки PDF, GraphML, завантаження API й незмінності головної статті записуються у `verification.json`; зміни джерел — у центральному журналі коду й `history.md`. Розподіли часів зараження, rho та частоти помилок не оцінювалися. Симуляцій немає.
