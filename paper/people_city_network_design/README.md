# Люди як вузли, міста як спільноти

[Пояснення PDF](article.pdf) · [редагований LaTeX](article.tex)

Окремий український документ без анотації та висновків. Пояснює, як побудувати персональну контактну мережу для SMPT, використовуючи місце проживання як сталу належність до міста. Містить перевірені приклади попередніх побудов, джерела, математичну конструкцію контактів, аудит французьких даних, вимоги до реалізації та протокол наступного генератора.

Це аналіз і підготовлені входи. Повний персональний граф країни та епідемічні траєкторії не створено. Основну SMPT-статтю, попередню шкільну мережу та комунальну мережу не змінено.

## Готові результати

- `analysis/v2/commune_inputs.csv`: населення, вікові групи, географія та два варіанти поділу, у порядку попередньої OD-матриці.
- `analysis/v2/partition_groups.csv`, `partition_summary.csv`, `summary.json`: детермінований аудит трьох поділів і меж регіонального прикладу.
- `analysis/v2/manifest.json`: хеші коду, входів та результатів; статус і час виконання. Дані v1 залишені незмінними; v2 уточнює формулювання NA і заголовок таблиці без зміни числових результатів. Точний код v1 збережено у `source_versions/3615d16784da642c313b48c1cd2139d5d85243f8c314e7fb6ec491251e3fba70/`.
- `contact_algebra.py`: невелика детермінована специфікація ваг контактних груп і підсумовування за домашнім містом. Це не масштабований генератор.
- `sources.json`, `downloads.jsonl`: джерела, ліцензія INSEE, контрольні суми й історія завантаження.

Усі 34858 кодів приєднано, але чотири рядки населення мають NA; їх не заповнено нулями. Для 21 комуни потрібне узгодження зайнятості з віковими сумами. Числа працівників у F та агрегованій Phi **не є контактними вагами W**. Поділ сільського населення за департаментами придатний лише як обчислювальний стресовий приклад, не як готове визначення міста.

## Відтворення

Із кореня репозиторію, у вже наявному середовищі:

```bash
.venv/bin/python paper/people_city_network_design/fetch_inputs.py
.venv/bin/python paper/people_city_network_design/analyze_design.py
.venv/bin/python -m unittest discover -s paper/people_city_network_design -p test_design.py -v
latexmk -cd -lualatex -interaction=nonstopmode -halt-on-error paper/people_city_network_design/article.tex
```

Перші дві команди перевіряють і пропускають наявні результати з відповідними хешами. Якщо код або входи змінилися, аудит потребує нової папки:

```bash
.venv/bin/python paper/people_city_network_design/analyze_design.py --output paper/people_city_network_design/analysis/v3
```

Після цього посилання на таблицю в LaTeX потрібно свідомо оновити. Попередні результати не перезаписуються. Це команди обробки даних, статичних тестів і компіляції, а не запуск симуляцій. Прямих нових Python-залежностей немає; XLSX читається через стандартні ZIP/XML-модулі.

Архів населення спочатку завантажився частково; сервер відхилив Range. Частковий файл збережено з суфіксом `.partial_...`, а робочий ZIP завантажено повністю. Частковий файл не використовується в аналізі.

Відкриті джерела попередніх побудов: [JRC, Франція](https://publications.jrc.ec.europa.eu/repository/handle/JRC128595), [Jiang et al., США](https://doi.org/10.1038/s41597-024-03970-1), [Faucher et al., Metz](https://doi.org/10.1038/s41467-022-29015-y). Їхні повні персональні файли в цю папку не завантажувалися. Стаття про США містить посилання на OSF; сумісність фактичних файлів із нашим API ще не перевірено.
