# Українська фінальна версія, розділи 1–5

Головний файл: ../main-SMPT_UK.tex; PDF поруч. Компілятор: LuaLaTeX. Локальні cas-sc.cls, cas-common.sty, cas-model2-names.bst та twoscale_references.bib обов’язкові.

Розділи 1–3 перенесено зі збереженої користувачем української версії без зміни змісту; прибрано лише оформлення документа для порівняння. Розділи 4–5 походять із after_4_5.tex: уточнено рівність інтенсивностей замість невизначеного генератора, умовність доведення та зв’язність джерела. Формули й параметри збережено. Анотація попередня. Посилання на розділи 6–7 та додатки зберігають номери повної статті; ці частини ще не включено.

Збірка: .venv/bin/python extrascripts/analysis/build_smpt_final_uk_sections_1_5.py
Після безпосереднього редагування main-SMPT_UK.tex компілюйте його LuaLaTeX; генератор захищає такі правки від перезапису.
