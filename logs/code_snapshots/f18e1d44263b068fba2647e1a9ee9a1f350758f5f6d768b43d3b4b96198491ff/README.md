# Простіший двомовний виклад секцій 1–3

Версія для перегляду від 2026-10-08. Англійський текст розташований ліворуч,
український — праворуч. Переписаний текст, формули, таблиця, підписи та алгоритм
позначені червоним. Схема використовує наявний рисунок, без генерування нових даних.

Головний результат: `../claude-version_merged_bilingual_UK_EN_plain_sections_1_3_red.pdf`.
Окремі мовні PDF: `../claude-version_merged_plain_sections_1_3_red_EN.pdf`
та `../claude-version_merged_plain_sections_1_3_red_UK.pdf`.

Зміни:

- Вступ починається з доступності даних: локальні контактні мережі та загальні
  транспортні, міграційні й мобільні дані між спільнотами.
- Прямо розмежовано початкову фізичну мережу, ідеальний процес на сурогатній
  мережі та реалізацію з часовою сіткою.
- Огляд літератури пояснює роботу згаданих методів простими словами.
- Формальний генератор замінено еквівалентними інтенсивностями зараження
  та видалення окремого вузла. Позначення для незміненого розділу 4 збережено.
- Час макроподії пояснено як перше досягнення випадкового порога накопиченою
  інтенсивністю. Правило з `inf` замінено рівністю інтеграла та порога,
  з явним поясненням першого досягнення й випадку без наступної події.
- Спрощено таблицю, підпис схеми й алгоритм. Алгоритм розміщено після
  пояснення його формул, а не як плаваючий блок перед ними.
- Опис імпорту в секції 3 узгоджено з поточною виправленою реалізацією:
  локальний симулятор зберігає невикористану частину експоненційного порога,
  перераховує час очікування й перевибирає тип події та вузол. Це уточнення
  опису коду, а не запуск симуляції чи оновлення старих числових результатів.
- Показник точності названо емпіричним для досліджених тестів; не заявлено,
  що його прогностичну цінність перевірено для довільних мереж.

Анотація, highlights, секції 4 і далі та бібліографічний файл не редагувалися.
Оригінальні файли збережено; додаткові копії містяться в `originals/`.
У `originals_manifest.json` записані їхні SHA-256. Нові сторінки можуть мати
іншу верстку та нумерацію сторінок. Номери шести формул у секціях 1–3,
мітки та послідовність усіх бібліографічних цитувань збережено.

Відтворення з кореня репозиторію:

```bash
.venv/bin/python extrascripts/analysis/build_smpt_readability_revision.py
```

Скрипт перевіряє незмінність оригіналів, цитувань і міток, збирає мовні PDF
та вирівнює початки секцій у двомовній версії. Якщо переклад потребує більше
сторінок, коротша версія отримує порожню половину сторінки. Це лише складання
документа; симуляції не запускаються.
