# Проста українська редакція розділів 1–3

- `sections_1_3_UK_before_after.pdf`: дві колонки українською, «До» ліворуч і «Після» праворуч. Відповідні фрагменти вирівняно за абзацами або цілісними блоками формул, таблиць, рисунка й алгоритму. Формат A3, альбомна орієнтація.
- `sections_1_3_UK_simple.pdf`: лише нова редакція, формат A4.
- `before.tex`: точна копія вихідного тексту на початку цієї роботи.
- `after.tex`: редагований текст розділів 1–3 для подальшого підключення до статті.
- `changes.diff`: порівняння джерел.
- `verification.json`: результати перевірки та контрольна сума вихідного тексту.

Основа: `../readability_revision_parallel_black_20261008/sections_1_3_UK.tex`.
Редакція пояснює простими словами спільний планувальник, імпорт інфекції, сурогатну мережу, точний подієвий варіант і оцінку інтенсивності за часовою сіткою. У вступі названо фактичні якісні висновки наявної статті. Умову випадкового рівномірного розміщення мостів для твердження про один експорт збережено. Емпіричний показник не подано як загальний закон.

Час міжспільнотного зараження не округлюється до точки сітки: реалізація оцінює його всередині інтервалу. Перестановочна перевірка оцінює сумісність відмінностей із випадковими коливаннями, а не доводить їхню причину.

Формули, бібліографічні цитування, мітки й геометрію TikZ-схеми збережено. Джерела базової статті не перезаписано. Пізніші розділи не редаговано; їхні номери використано для посилань. Для PDF порівняння бібліографію наведено один раз після обох колонок. Жодних симуляцій або нових числових результатів ця робота не створює.

Збірка з кореня репозиторію в Linux/WSL:

```bash
.venv/bin/python extrascripts/analysis/build_smpt_uk_before_after.py
```

Потрібні встановлені LuaLaTeX і pdftotext та наявні AUX/BBL української базової версії. Скрипт перевіряє незмінність вихідного тексту, формул, міток, цитувань і TikZ та відсутність нерозв'язаних посилань, відсутніх символів і переповнених блоків у PDF.
