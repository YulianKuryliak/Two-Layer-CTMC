# Короткий огляд індивідуальних мереж

[Читати PDF](review.pdf) · [редагований LaTeX](review.tex) · [текст для пошуку](review.txt)

Окремий пояснювальний документ українською, без анотації та формальних висновків. Сім досліджень: Salathé, Eubank, Guarino, Machens, Génois, Mistry та Chang. Для кожного коротко описані дані, зміст вузлів/ребер і те, що саме перевіряли.

Включено:

- виміряну індивідуальну мережу школи;
- синтетичні міські мережі та два конкретні приклади ASPL/кластеризації;
- реконструкцію з контактних матриць та неповної вибірки людей;
- перевірку вікового змішування на незалежних контактних опитуваннях;
- модель потоків до місць діяльності, з чіткою відмінністю від персонального графа.

Це цільовий огляд прикладів, а не систематичний огляд усієї літератури. Виміряні контакти, модельні соціальні ребра, транспортні потоки й перевірки епідемій явно розрізнені. Жодних нових мережевих метрик чи симуляцій не обчислювали. Основну SMPT-статтю й попередні документи не редагували.

`sources.json` містить первинні джерела, місця перевірених тверджень і чисел. Числа Guarino переписані з таблиці6 (PDF-сторінка20); область усереднення ASPL незалежно не встановлена й це зазначено біля таблиці в огляді. `sources/guarino2021.pdf` — завантажена авторська копія опублікованої роботи, не наш текст; поряд є її текст і зображення перевіреної сторінки. Інші первинні джерела прочитано через веб-пошук/повні сторінки, без завантаження контактних датасетів.

Команда компіляції з кореня проєкту:

```bash
latexmk -cd -lualatex -interaction=nonstopmode -halt-on-error paper/individual_networks_review/review.tex
```

Використовується наявний LuaLaTeX/DejaVu; нових залежностей немає. `verification.json` фіксує перевірку посилань, таблиці, наукових формулювань і PDF.
