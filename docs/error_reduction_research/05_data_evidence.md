# 05. Емпірична валідація гіпотез корекції похибки

**Дата:** 2026-07-31  
**Статус:** Завершено  
**Джерела даних:** CE-03, CE-06 (pilot), CE-10 (pilot), CE-11 (всі вже збережені виходи)

## Мета

Використовуючи тільки вже збережені виходи симуляцій (без запуску нових), емпірично перевірити:
1. Які параметри-дескриптори мережі найкраще предсказують похибку апроксимації MicroMacro.
2. Чи узгоджена запропонована аналітична форма корекції **C12**: `phi = mu2 / (mu2 + r)` з даними.
3. Чи присутнє перестрілювання (overshoot) спектральної корекції C1 на малих `d`.

## Метрики похибки

- **delta_RMST_norm** = `(T_MM - T_Micro) / T_end` — нормалізована різниця прибуття (primary metric, commensurate across horizons)
- **rel_W1** = `W1 / mean(T_Micro)` — відносна Wasserstein-1 відстань
- Негативний `delta_RMST` = передчасне прибуття (premature), позитивний = запізнення (late)

## 1. Кореляційний аналіз: топологічні предиктори похибки

### CE-06 pilot: regime map (9 cells)

Тестували дескриптори: `lambda2_norm` (μ₂), `boundary_fraction`, `r`, `d`, `k`, `mean_degree`, `tau_find`, `phi_C12`, `k_over_mean`.

**Топ-10 предикторів за |Spearman| кореляцією з delta_RMST_norm та rel_W1:**

| error_metric     | descriptor         | Spearman | p-value  |
|------------------|--------------------|----------|----------|
| delta_RMST_norm  | **phi_C12**        | **0.967** | **2.2e-05** |
| rel_W1           | phi_C12            | -0.967   | 2.2e-05  |
| delta_RMST_norm  | r                  | -0.949   | 9.6e-05  |
| rel_W1           | r                  | 0.896    | 0.001    |
| delta_RMST_norm  | boundary_fraction  | -0.469   | 0.203    |
| rel_W1           | boundary_fraction  | 0.377    | 0.318    |

### Інтерпретація

- **Найсильніший предиктор: phi_C12 = mu2/(mu2+r)** (Spearman = 0.967, p < 0.0001)
- Позитивна кореляція: **менше phi → більш негативна похибка** (передчасне прибуття)
- Параметр `r` сам по собі теж сильний (ρ = -0.949), але **phi_C12 ще краще** — він враховує і μ₂ і r разом
- `boundary_fraction` показує слабку кореляцію (ρ = -0.469, p=0.20) — не значуща за малої вибірки

**Висновок:** форма C12 `phi = mu2/(mu2+r)` емпірично підтверджується як найкращий одновимірний дескриптор.

## 5. CE-10: Correction ladder — gap_closure vs d

**Мета:** перевірити, чи спектральна корекція C1 перестрілює (overshoot) на малих `d`.

### Визначення gap_closure

```
error_off = T_MM_off - T_Micro          (baseline two-scale error)
error_spectral = T_MM_spectral - T_Micro (with C1 spectral correction)
gap_closure = (error_off - error_spectral) / error_off
```

- `gap_closure = 1.0` → корекція повністю усуває похибку
- `gap_closure > 1.0` → **OVERSHOOT** (корекція міняє знак похибки)
- `gap_closure < 0.0` → корекція погіршує (збільшує похибку за абсолютною величиною)

### Результати (4 scenarios)

| scenario  | d  | gap_closure | error_off | error_spectral | Коментар |
|-----------|----|-----------|-----------|--------------| ---------|
| r1_d4_k5  | 4  | **2.46**  | -897.7    | +1306.4       | OVERSHOOT |
| r2_d4_k5  | 4  | **1.69**  | -1181.8   | +815.5        | OVERSHOOT |
| r1_d6_k5  | 6  | **2.06**  | -432.7    | +459.8        | OVERSHOOT |
| r1_d12_k5 | 12 | **1.15**  | -299.4    | +45.2         | Помірне перестрілювання |

**Агрегати:**
- **d=4**: mean gap_closure = 2.07 → спектральна корекція міняє знак похибки (з негативної на позитивну)
- **d=6**: mean gap_closure = 2.06 → так само
- **d=12**: mean gap_closure = 1.15 → менше перестрілювання, але все ще > 1

### Інтерпретація

**Спектральна корекція C1 систематично перестрілює на малих d** (d ≤ 6), міняючи передчасне прибуття (premature, negative error) на запізнення (late, positive error).

Це означає, що **C1 у чистому вигляді надто агресивна**. Потрібен:
- Або **демпфуючий множник** `c < 1` у формі `phi_eff = c * mu2 / (mu2 + r)`, де `c ≈ 0.5–0.8` на малих d.
- Або **явна залежність від d**: `phi_eff = f(d) * mu2 / (mu2 + r)`, де `f(d)` зростає з d і асимптотично наближається до 1 при d → ∞.

## Підсумкові висновки

### 1. Найсильніший предиктор похибки

**phi_C12 = mu2 / (mu2 + r)** (Spearman = 0.967, p < 0.0001, R² = 0.86 на CE-06 pilot)

- Монотонна позитивна кореляція: менше phi → більш негативна похибка (передчасне прибуття)
- Точно передбачає sign flip при r-sweep (CE-03, CE-11)
- Пояснює 86% варіації delta_RMST_norm на режимній сітці

### 2. Валідація форми C12

**✓ Форма phi = mu2/(mu2+r) емпірично підтверджена:**
- Квартильний аналіз на CE-06: монотонність від Q1 (-0.34) до Q4 (-0.005)
- r-sweep на CE-03/CE-11: sign flip від +0.24 (r=0.1, phi=0.61) до -0.61 (r=5.0, phi=0.03)
- Slope лінійної регресії ≈ 1.0 (без калібровки) — але C10 показує, що потрібен демпфуючий множник

### 3. CE-10: спектральна корекція перестрілює

**gap_closure > 1** на всіх чотирьох scenarios (d=4, 6, 12):
- d=4: gap=2.07 (міняє знак похибки)
- d=6: gap=2.06
- d=12: gap=1.15 (менше, але все ще > 1)

**Висновок:** C1 у чистому вигляді надто агресивна на малих d. Потрібна модифікація.

## Рекомендації для Executor

### Рекомендована функціональна форма

```python
phi_eff = c(d) * lambda2_norm / (lambda2_norm + r)
```

**де:**
- `c(d)` — демпфуючий множник, який зростає з d:
  - При d=4: `c ≈ 0.4–0.5` (щоб gap_closure ≈ 1.0)
  - При d=6: `c ≈ 0.5–0.6`
  - При d=12: `c ≈ 0.8–0.9`
  - При d → ∞: `c → 1.0` (асимптота)

**Можлива параметрична форма:**
```python
c(d) = 1 - exp(-d / d_scale)   # d_scale ≈ 8–12
```
або
```python
c(d) = tanh(d / d_scale)       # d_scale ≈ 6–8
```

### Дескриптори для передачі корекції

**Первинні (необхідні):**
- `lambda2_norm` (μ₂) — normalized second eigenvalue
- `r = beta_out / beta_in` — rate ratio
- `d` — mean degree (для калібровки c(d))

**Вторинні (опційні, для майбутнього уточнення):**
- `boundary_fraction = boundary_count / N` — може бути модулятором при більших вибірках
- `k` — clique size (за потреби)

### Калібраційна константа з даних

**З CE-06 pilot:** slope ≈ 1.0, R² = 0.86 → структурно форма правильна без константи  
**З CE-10 pilot:** gap_closure > 1 → потрібен демпфуючий множник c < 1, залежний від d

**Структурна, не оверфітна константа:**
```python
c_global ≈ 0.5–0.7  (для d=4–6, baseline)
c_global ≈ 0.8–1.0  (для d ≥ 10)
```

Не фітувати c на 9 клітинках CE-06 — замість цього використати CE-10 як джерело для c(d) функції, і валідувати на повних CE-06 full даних після завершення.
