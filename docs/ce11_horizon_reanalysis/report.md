# CE-11 — Horizon-Controlled Re-Analysis of CE-03

## Мета

Усунення confound горизонту часу T_end у вихідному аналізі CE-03. Оригінальні сценарії використовували різні T_end (r=0.1 → 20000, r=5.0 → 2000). Через 10-кратну різницю горизонтів сирий ΔRMST не є порівнянним між сценаріями.

**Рішення**: переобчислити метрики з урахуванням горизонту:
- **ΔRMST_norm** = ΔRMST / T_end
- **rel_W1** = W1 / mean(T_Micro)
- **W1/IQR** — Wasserstein нормалізована на міжквартильний діапазон
- **Δp** = p_MM − p_Micro

## Ключові спостереження

### 1. Зміна знаку ΔRMST_norm

**Так**, спостерігається зміна знаку ΔRMST_norm при зміні r. Перехід від запізнілого (late, ΔRMST>0) до передчасного (premature, ΔRMST<0) прибуття.

**Точка переходу**: між r=0.3 та r=1.0.

### 2. Ймовірність завершення епідемії

При r=5.0: p_Micro=0.01, p_MM=1.00. При високих beta_out Full Micro часто не досягає кінцевого шару до T_end.

### 3. Confound горизонту

Сирий ΔRMST змінюється від +4795.9 до -1638.4. Ця варіація частково зумовлена різницею T_end. Нормалізований ΔRMST_norm дає чистіший сигнал.

### 4. Wasserstein відстань

rel_W1 залишається відносно стабільним (~0.2–0.6).

### 5. Kaplan-Meier RMST

ΔRMST_KM узгоджується з ΔRMST за знаком і магнітудою.

## Висновки

1. **ΔRMST_norm є ключовою метрикою** для порівняння якості апроксимації.
2. **Знак ΔRMST_norm змінюється з r**: від позитивного при низьких r до негативного при високих r.
3. **Різниця Δp критична**: при r=5.0 p_Micro=0.01.
4. **rel_W1 та W1/IQR** підтверджують відносну відстань.
5. **Kaplan-Meier RMST** узгоджується з простою стратегією.

## Примітки

- Всі метрики обчислені на основі збережених даних CE-03.
- Terminal arrival = layer=9.
- Bootstrap CI: 1000 ресемплів.
